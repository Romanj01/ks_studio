# KS Studio — GitHub Pages

Это отдельная статическая версия KS Studio для Ногинска. Все действия демонстрационные и сохраняются в браузере посетителя. Реальные записи в студию, письма и Telegram-сообщения не отправляются.

Для публикации загрузите содержимое этой папки в корень отдельного репозитория. В Settings → Pages выберите Deploy from a branch → main → /(root). Публикуется именно эта папка, а не VPS-версия. Изображения уже включены в архив.

Локальный просмотр: `node preview.mjs` или `start.cmd`; адрес http://127.0.0.1:4354/ks-studio-noginsk/ . Демо-администратор: **admin / 0123456789**.

Контакты по присланной карточке: Ногинск, ГСК «За Рулём-2», +7 (916) 689-77-78. График, услуги и прайс требуют подтверждения студией. Начальные услуги и время — примеры для проверки интерфейса. Стоимость показывается «По согласованию».

Галерея создана с помощью ИИ и отмечена как демонстрационная. Это не реальные работы KS Studio. Для изменения начального сайта для всех посетителей редактируйте `demo-seed.js`; изменения через демо-админку видны только в вашем браузере.

Проверки: `node check.mjs`, `node --test demo.test.mjs`. Сборка и npm-зависимости для GitHub Pages не нужны.
